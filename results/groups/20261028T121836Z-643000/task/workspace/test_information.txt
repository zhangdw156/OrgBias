The Comparison Desk report is available through get_comparison_report and covers the exact configurations in the quote index.
For the battery comparison, all six systems ran the same repeating workload: browser pages and document editing, a local spreadsheet recalculation, and a 20-minute video-call segment in each hour. Screens were calibrated to 200 cd/m2 and 60 Hz, Wi-Fi was on, keyboard lighting was off, and the room was held at 22 degrees Celsius. All systems used Windows 11 Balanced mode and the same application versions. The report gives two runs per configuration, not a prediction of the exact runtime every user will obtain.
The multitasking check used the user's described applications and a small Python notebook. A separate longer batch test illustrates performance headroom; it does not represent the user's typical workload.
The quoted marketing battery figures use each offer's own video-playback protocol. Those protocols vary in brightness, power mode, and network use; the comparison report describes a different workload.
One sample unit per quote configuration was available. The report contains no longitudinal failure-rate study. Display reflections and keyboard observations were made during the same office session.
